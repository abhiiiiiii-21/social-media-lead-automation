CODING RULES

Before writing code:

1. Think about the architecture.

2. Reuse existing components.

3. Reuse existing hooks.

4. Reuse existing utilities.

5. Do not duplicate logic.

6. Keep files modular.

7. Keep components under ~200 lines where practical; split large components into smaller ones.

8. Build scalable production-ready code.

9. Follow Next.js 15 App Router best practices.

10. Use TypeScript everywhere.

11. If a shadcn component exists, use it.

12. Explain your implementation plan before generating code.
